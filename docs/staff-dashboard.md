# Staff dashboard — preview

This custom Lovelace card is a local-only simulation with a fictional employee and public demonstration PIN 1234. No API, network requests, live employee data, credentials, or HA actions. Do not enter real staff PINs. Gross shift elapsed time is independent of breaks. Confirmations reset after five seconds; action choices time out after twenty seconds. Refresh resets the entire demo.

The HA Staff dashboard is an administrator-only preview. Dashboard visibility is NOT a security boundary for the wider Home Assistant API. Do not give the shared staff kiosk HA credentials. Production terminal will be a separate restricted endpoint hosted by the integration, with authenticated terminal provisioning, secure transport, PIN validation, rate limiting and server-side state enforcement. The administrator dashboard may link to it. Do not enable until runtime tests and security review. No integration installation or RotaCloud API change is implied by installing this preview.
