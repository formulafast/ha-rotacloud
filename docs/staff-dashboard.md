# Staff dashboard — preview

This custom Lovelace card is a local-only simulation with a fictional employee and public demonstration PIN 1234. No API, network requests, live employee data, credentials, or HA actions. Do not enter real staff PINs. Gross shift elapsed time is independent of breaks. Confirmations reset after five seconds; action choices time out after twenty seconds. Refresh resets the entire demo.

The preview card stays offline. For the live terminal inside an existing authenticated HA administrator session, see [0.4.0 terminal setup](release-notes-0.4.0.md). A standalone kiosk endpoint is deferred. Dashboard visibility is NOT a security boundary for the wider Home Assistant API. No integration installation or RotaCloud API change is implied by installing this preview.
